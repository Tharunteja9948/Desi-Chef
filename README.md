# AI Chef

An Indian homestyle recipe engine that suggests dishes based on the ingredients you have at home. It includes 512 recipes across 10 categories (Breakfast, Biryani & Rice, Curries, Street Food, Snacks, Breads, Sweets, Chutneys, Soups & Chai, Seafood & Eggs) with ingredient matching, search, servings scaling, and step-by-step cooking timers.

## Running Locally

Open `index.html` in any browser, or run:

```bash
python -m http.server 8000
```
